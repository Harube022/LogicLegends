# Menu scrollbar

Created 2026-10-14 with the built-in image generation tool from the user's cropped scrollbar reference. The two independent sprites match the reference's dark rounded brown track and tan rounded thumb with restrained painted shading. Unity imports each part with nine-slice borders, so the artwork stretches without distorting its caps.

Used by the Main Menu achievement and customization lists. The thumb is a separate native Unity Scrollbar handle, rather than a position painted into the track. The source reference and other UI artwork remain unchanged. Full prompt: `generation-prompt.json`.
