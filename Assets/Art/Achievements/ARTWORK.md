# Achievement panel

Created 2026-10-14 with the built-in image generation tool from the user-approved achievements concept. Warm matte painted brown wood, clipped corners, cream interior and a blank integrated title plaque follow `artstyle.md` and the shared GraphHUD frame family.

`AchievementsPanel.png` contains the background only. All labels, achievement cards, rewards and the interactive scrollbar remain separate Unity UI objects. No text, claim status, currencies, scrollbar or scroll hint is baked into the image. The source artwork remains unchanged.

The generation prompt is recorded in `generation-prompt.json`. This asset is used only by Main Menu achievements.
