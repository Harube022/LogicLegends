# RulesOfInference board presentation

This folder is used only by `Assets/Scenes/RulesOfInference.unity`.
The shared inference builders, drag handlers, crystal logic, HUD assets and other scenes are unchanged.

- `InferenceBoardPresentation` applies the artstyle.md gameplay palette, scene layout, runtime-created word styling and existing button callbacks. Edit Mode retains the world-space preview; Play Mode presents the board as an overlay inside the safe area, centered and enlarged to cover the stone viewing area. Gameplay remains paused through the existing challenge manager. Controls and the minimap are hidden while viewing and restored on exit. The board stays transparent with input blocked until VCam_RulesOfInference is active and Cinemachine reports the blend complete.
- `InferenceAction.png` is a reference-based blank derivative of `Assets/Assets/Interface_Sprites/play_interface/btn_solo(1).png`: remove SOLO, reconstruct the inset face, recolor only that face to teal #294F54, preserve the wood/bronze rim, bevel and shading, transparent surroundings, no added labels/icons. Source was inspected alongside `Assets/Interface_Sprites/main_menu_interface/btn_play.png` before editing. The derivative is 2188x718, Sprite Single, alpha transparency, no mipmaps, no compression, no sliced borders. It is displayed with Preserve Aspect in a 360x118 rect; editable IMPACT TMP text supplies labels. Pointer/disabled feedback affects an inset face overlay and text, leaving the frame untinted.
- `InferenceBody.asset` is a local copy of LiberationSans SDF. Its local `InferenceMath` fallback uses the project's NotoSansMath-Regular.ttf and a static atlas covering ∴ ∧ ∨ ¬ → ↔ ∀ ∃ ⊕ ⊤ ⊥. Shared font fallback tables remain unchanged.
- `InferenceTilePresentation` adds selection, drag target, incorrect blank and locked success feedback without changing drop or touch logic. Simple inset tiles are intentional for uncluttered puzzle content.
- The premises and word bank scroll when content exceeds their viewports. Existing editable text and rule data continue to own feedback, hidden/revealed conclusions, crystal search, retry and next-round states.

The guide is unchanged: this applies its existing design family rather than establishing a new convention.

Validation: Unity MCP Play Mode checked 1920x1080, 1280x720 and 2160x1080 landscape. Checked 72 rule/form/example layouts for horizontal containment, plus scroll overflow; pointer raycasts and distinct finger IDs through the unchanged drag/drop handlers; empty/error feedback, premise locking, physical pillar-crystal pickup/carry/place, wrong-crystal removal, success/conclusion math glyph, replay and exit restoration. The scene starts with legacy timers inactive; an active timer is presented at the header and restored on exit without starting/changing its manager. Editor reported an existing Unity Remote requirements failure, so Android hardware/touchscreen validation is not claimed. Play Mode's existing LowPolyWater script mutates its shared mesh, and Unity rewrites the already-modified Ocean50x50W750H750.asset; exclude that asset and other pre-existing changes from this UI commit.


Viewing-size follow-up: the world-space preview scale is 0.025 (2.5 times its previous size). The runtime panel is centered and fits 96% of the safe-area width / 94% of its height. Gameplay controls and the separately managed minimap stay hidden during viewing, with their prior CanvasGroup states restored on exit. The board is transparent and noninteractive until the requested CinemachineCamera is active and the Brain's actual blend finishes. Checked 118 blending frames with no board visibility/input, exit restoration, interrupted-open cancellation, reopening, and touch-pointer drag at the larger scale. Checked 1920x1080, 2160x1080 and 1280x720 landscape views. Shared water mesh was restored to its state at the start of this follow-up after Play Mode validation.
