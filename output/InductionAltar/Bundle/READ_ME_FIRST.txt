Import InductionAltar.unitypackage into Unity 6 with URP and TextMeshPro.
The package includes the fonts and atlas dependencies used by the labels.
Then use Assets/Art/InductionAltar/Prefabs/Altar_BaseCase,
Altar_InductiveHypothesis, or Altar_InductiveStep.
Each uses exactly the same mesh assets; colors and editable TMP labels differ.
For standalone FBX use Assets/Art/InductionAltar/InductionAltar_Shared.fbx.
The optional InductionAltar_Boards.fbx contains only the blank boards.
Blender source, three studio previews, the actual Unity render, and validation
reports are in SourceAssets/InductionAltar. Generation source is in Tools.
See Assets/Art/InductionAltar/README.txt for board swaps and text editing.
Only altar and board assets are included. No gameplay scene is added.
