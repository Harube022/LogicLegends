Behavior
The existing shared display serves all ten solo trials. It now aligns directly
under the actual Settings and Help controls: left edge at Settings, right edge at
Help, with a 12-reference-unit gap below the lower control. Width follows those
controls; height follows wrapped text. Padding includes the actual nine-slice
border plus internal breathing room. Body text uses the existing bold reading
font, with no auto-shrinking and a 15-screen-pixel minimum at small resolutions.
The notice badge and text have separate padded areas. Existing fantasy wood art
is retained; no new UI textures or shaders were made.

One .36-second eased entrance slides from entirely off-screen left. After settling,
the border and notice icon repeat a gentle 2.8-second heartbeat; text and panel
geometry stay steady. See HintHeartbeat-2026-11-07.txt for current verification. Completing
the required action reverses the same motion clock into a .28-second left exit.
A replacement waits until old text is off-screen; latest pending content wins.
Reversing during entrance/exit preserves position without competing coroutines.

The supplied Downloads/Notification.mp3 was copied byte-for-byte into Resources;
source and copy SHA256 hashes match. Unity imports it as a preloaded mono 1.152s
clip, decompressed on load. One 2D, non-looping AudioSource uses the existing SFX
mixer group at .8 base gain, so saved SFX volume/mute continues to apply. A new
notification stops the previous voice before its one shot. Action identity tracks
which cue has played: text refreshes, normal frames, repeated Show Hint requests
and modal resume do not duplicate the sound. Help/modals and scene/terminal cleanup
stop any active cue. No Music-volume setting is changed.

The 30-second inactivity state model and all trial-specific action providers are
unchanged. Help/tutorial/quiz/reading/camera pauses still exclude hint waiting.
Admin authorization and its delay-bypass command are retained. Hints stay
non-interactive: no GraphicRaycaster, CanvasGroup input disabled, graphics do not
receive raycasts. Game Over/completion/source loss clear immediately to keep
results unobstructed. Ordinary action changes animate out.

A portrait timing issue was found during verification: Formal's Update temporarily
resizes Help before its shared LateUpdate dock. Event handlers now update logical
hint state only. Rendering/measuring happens in the shared component's LateUpdate
after the dock; the cached text measurement avoids rebuilding global UI each frame.
